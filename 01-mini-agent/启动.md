# 启动 mini-agent

一次性命令行 Agent：你给一句任务，它在 `playground/` 里读文件、改文件、跑命令，结束后进程退出。没有网页。

需要 Node.js 22+。本机若默认是 Node 20，先执行：

```powershell
nvm use 22.20.0
```

## 安装

```powershell
cd D:\2026Code\jianfeng-Agent\01-mini-agent
pnpm install
```

## 无密钥试跑

不调 DeepSeek，用内置假模型走一遍循环，并写入 `playground/hello.ts`：

```powershell
pnpm start -- --fake "写一个 hello.ts"
```

终端会出现类似：

```text
[step 1] edit {"path":"hello.ts","old_text":"","new_text":"console.log('ok');\n"}
已写入 hello.ts

已在 playground/hello.ts 写入 console.log('ok')
```

## 真模型

1. 复制环境变量文件：

```powershell
copy .env.example .env
```

2. 编辑 `.env`，填入 [DeepSeek API Key](https://platform.deepseek.com/)：

```env
DEEPSEEK_API_KEY=sk-你的密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
```

3. 启动一次任务（Agent 只能改 `playground/`）：

```powershell
pnpm start "在 playground 里写一个 hello.ts，内容是 console.log('ok')"
```

## 测试
